# v1.3.10 - Modal Overlay & Sparkle Position Fixes

**Released:** February 1, 2026

## Summary

Fixed two visual bugs on the landing page when scrolled below the fold: modal content bleeding through the backdrop, and cursor sparkles appearing displaced from the mouse position.

---

## What Changed

### Modal Overlay Fixes (`ReadMySpreadModal.tsx`)

**Problem:** When opening the "Read My Spread" modal after scrolling down the page, text from the below-fold content (e.g., "Each tarot card...") was visible through the modal backdrop. Links behind the modal were also clickable.

**Root Cause:** The modal was rendered inside a `relative z-10` container (the Hero Section), creating a stacking context. Even with `z-[60]`, the modal couldn't layer above sibling elements (below-fold content) that also had `z-10`.

**Solution:**
- Use `createPortal` to render modal directly to `document.body`, escaping parent stacking contexts
- Increased z-index from `z-[60]` to `z-[9999]`
- Increased backdrop opacity from `bg-black/70` to `bg-black/90`
- Added scroll lock on body when modal opens (preserves scroll position on close)
- Added backdrop click handler to close modal

### Sparkle Position Fix (`SparkleBackground.tsx`)

**Problem:** When scrolled down the page, cursor sparkles appeared displaced from the actual mouse position (shifted upward by the scroll distance).

**Root Cause:** Sparkles used `clientX/clientY` (viewport-relative coordinates) but were positioned with `left/top` in an `absolute` container that scrolls with page content.

**Solution:** Changed from `clientX/clientY` to `pageX/pageY` which includes scroll offset, ensuring sparkles appear at the correct document position regardless of scroll.

## Technical Notes

### Portal Pattern for Modals

Using `createPortal` is the standard React pattern for modals that need to escape parent stacking contexts. The modal renders at the DOM root level while maintaining React's component hierarchy for state and events.

```tsx
import { createPortal } from 'react-dom';

// Render modal outside parent stacking context
return createPortal(modalContent, document.body);
```

### Viewport vs Document Coordinates

- `clientX/clientY` - Position relative to viewport (0,0 is top-left of visible area)
- `pageX/pageY` - Position relative to document (includes scroll offset)

When positioning elements in a scrollable container, use `pageX/pageY` to account for scroll position.
