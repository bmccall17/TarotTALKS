# v1.6.2 - Social Campaign Asset Pipeline & Signal Deck Parity 📸🎨

**Released:** Feb 6, 2026

## Summary
Multi-platform social campaign CLI pipeline with Instagram image parity, UGC styling, AI caption generation, Signal Deck UI enhancements, and a one-command pipeline to generate Instagram assets for all 78 cards.

---

## Features

### Phase 1: Instagram Feed Image Generators
- Instagram Feed portrait (1080x1350) image routes for cards and talks
- Extracted shared Satori helpers (fonts, sparkles) into `satori-helpers.ts`
- Added `instagram-feed` and `linkedin` types to storage pipeline
- LinkedIn images stored via OG generator under `linkedin` bucket path

### Phase 2: Campaign CLI Pipeline
- `campaign:ingest` - Build manifest from Signal Deck DB, CSV, or JSON input
- `campaign:download` - Fetch source images with 3x retry + exponential backoff
- `campaign:render` - Sharp resize to platform specs (Instagram 4:5, X/Bluesky/LinkedIn OG cards)
- `campaign:index` - Generate per-platform `_index.csv` and `_summary.json`
- All scripts idempotent (safe to re-run), follow existing `dotenv + tsx` pattern
- Output to `/campaigns/` directory (gitignored)

### Phase 3: UGC Image Styling
- Sharp-based treatments: slight crop offset, grain noise overlay, warm color shift, SVG watermark, JPEG quality 88
- Produces `ugc_` prefixed variants alongside clean renders via `--ugc` flag

### Phase 4: Gemini Caption Generation
- Platform-aware AI captions (short/medium/spicy variants + hashtags with `#` prefix)
- Reuses existing `generateWithGemini()` with retry, rate limiting, cost tracking
- ~$0.0001 per item via Gemini 2.0 Flash
- Integrated into render script via `--captions` flag

### Phase 5: Signal Deck UI Enhancements
- **PostPreview** component - Platform-specific post mockups with live card/talk images (IG, X, Bluesky, LinkedIn)
- **HashtagSuggester** component - Card-aware hashtag pools, all tags selected by default, click-to-deselect and copy
- **ExportToCampaign** component - Bulk export selected shares as campaign JSON, auto-closes after download
- Multi-select mode with Select/Export buttons inline with date filters
- Per-share export button (download icon) on each ShareRow
- ShareFilters now accepts `leftActions` slot for inline controls

### Phase 6: All-in-One UGC Script
- `campaign:ugc` - Single command: ingest -> download -> render (UGC + captions) -> index
- **`--source all-cards`** mode - Queries all 78 cards from DB, bypasses Signal Deck entirely
- Live Satori route URLs for image downloads (always available, no pre-generation needed)
- Smart manifest merge: refreshes existing items with latest data instead of skipping stale entries
