# v1.3.12 - Tarot-Themed 404 Page

**Released:** February 2, 2026

## Summary

A delightful custom 404 page that transforms "page not found" into a moment of discovery. Users who land on a broken link are greeted by a random reversed tarot card from a curated "lost" collection, each with playful, thematic copy that turns an error into a golden nugget of brand personality.

---

## The Concept

Instead of a boring "404 - Page Not Found", users encounter one of six thematically appropriate reversed cards:

| Card | Message | Button |
|------|---------|--------|
| The Tower | "Well, this page has collapsed! Something broke, but hey—sometimes destruction clears the path." | Rise from the rubble |
| The Hanged Man | "You're stuck in limbo! This page is suspended somewhere in the void. Time for a new perspective." | Find a new view |
| The Moon | "Lost in the fog? This page doesn't exist—or maybe it never did. Hard to tell in this light." | Step into the light |
| Death | "This page has passed on. Don't mourn it too long—transformation awaits elsewhere." | Begin again |
| Eight of Cups | "This page walked away. Sometimes you have to leave what's empty behind." | Move forward |
| Five of Pentacles | "Left out in the cold? This page isn't here, but warmth is just a click away." | Come inside |

---

## Features

- **Random card on each visit** — Uses `force-dynamic` to ensure true randomization on each request
- **Reversed card display** — Card image rotated 180° to indicate "reversed" position
- **Clickable card** — Tapping the card navigates to its detail page (`/cards/{slug}`)
- **Card-specific CTA** — Each card has a unique, thematic button that returns home
- **Consistent styling** — Matches landing page card sizing (`200x340px` / `220x370px`)
- **Hover effects** — Indigo glow on card hover, matching the ritual card behavior

## Technical Notes

### Force Dynamic Rendering
```tsx
export const dynamic = 'force-dynamic';
```
This ensures the `Math.random()` call executes on each request rather than being cached at build time.

### Card Images
All images served from Supabase storage:
```
https://hldbacbxyosqpbsataqt.supabase.co/storage/v1/object/public/card-images/{slug}.jpg
```

### Sizing Match
Card dimensions match the landing page ritual cards exactly:
- Mobile: `w-[200px] h-[340px]`
- Desktop: `md:w-[220px] md:h-[370px]`

## Why This Matters

404 pages are often overlooked, but they're a moment of truth for user experience. When someone hits a dead end, you can either frustrate them with a generic error or delight them with something unexpected.

This 404 page:
- Stays on-brand with tarot imagery
- Provides playful, empathetic copy
- Offers clear navigation back to the app
- Creates a mini discovery moment (users can explore the card they saw)
- Turns a negative experience into a positive touchpoint

**A golden nugget of delight in the app.**
