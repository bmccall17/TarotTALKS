# v1.6.0 - Static Social Share Images via Supabase Storage

**Released:** Feb 6, 2026

## Summary
Pre-generate all social share images (OG, Twitter, Instagram) as static PNGs in Supabase Storage so social platform crawlers fetch from CDN instead of triggering Vercel serverless Satori generators. Eliminates serverless function invocations for every share link crawl, keeping the app well within Vercel's free tier.

---

## Features
- **Static share image pipeline**: New `share-images` Supabase Storage bucket with deterministic paths (`{category}/{type}/{slug}.png`)
- **Generation API**: `POST /api/admin/share-images/generate` fetches from existing Satori generators, uploads PNGs to Supabase, and updates `share_image_url` in DB
- **List API**: `GET /api/admin/share-images/list` queries Supabase bucket to show which images exist per category/type
- **Thumbnail upscale API**: `POST /api/admin/talks/[id]/upscale-thumbnail` downloads external thumbnails, upscales to 1280x720 WebP, and stores in Supabase
- **Metadata fallback chain**: Pages now prefer `shareImageUrl` (static Supabase) > `thumbnailUrl` (raw thumbnail) > dynamic Satori generator
- **Cards Twitter image unified**: Cards now use the same OG image URL for both OpenGraph and Twitter (was separate before)
- **Spreads Twitter image added**: Spreads now include `images` in the Twitter card metadata
- **Admin Share Images page rewrite**: Now reads from Supabase Storage instead of local filesystem, with per-item Generate buttons, "Generate All Missing" batch with progress bar, DB URL status tracking
- **Admin TalkRow**: New ImagePlus button that upscales thumbnail + generates all share images in one click
- **Admin CardRow**: New ImagePlus button that generates all share images in one click
- **Admin Edit pages**: Live site URLs at top of Preview boxes (click to copy, right-click for normal menu), clickable previews linking to live pages in new tabs
- **DB migration**: `share_image_url` column added to `talks`, `cards`, and `spreads` tables
- **Clickable titles in Share Images admin**: Card/talk names link to their admin edit pages

## Pre-Deploy Steps
1. Create `share-images` bucket in Supabase Dashboard (set to Public)
2. Run migration SQL in Supabase SQL Editor:
   ```sql
   ALTER TABLE talks ADD COLUMN share_image_url text;
   ALTER TABLE cards ADD COLUMN share_image_url text;
   ALTER TABLE spreads ADD COLUMN share_image_url text;
   ```

## Post-Deploy Steps
1. Go to `https://tarottalks.app/admin/share-images`
2. Cards tab: "Generate All Missing" (78 cards x 4 images = 312 images)
3. Talks tab: "Generate All Missing" (~81 talks x 3 images = 243 images)
