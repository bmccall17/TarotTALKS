# v1.6.4 - Supabase Egress Reduction: Image Proxy & Query Caching

**Released:** Feb 8, 2026

## Summary
Structural fixes to stay within Supabase Free Tier's 5GB/month cached egress limit. Eliminates ~95% of egress by routing all images through Vercel's CDN optimization proxy, switching listing pages from SSR to ISR, fixing N+1 database queries, and adding query-level caching with tag-based invalidation.

---

## Features

### Phase 1: Image Optimization (~70-80% egress reduction)
- Removed `unoptimized: true` from `next.config.ts` — enables Vercel's built-in image optimization proxy (images fetched from Supabase once, then cached as optimized WebP on Vercel CDN)
- Converted all public-facing `<img>` tags to Next.js `<Image>` components so they route through `/_next/image` proxy instead of hitting Supabase directly
- HAR verification confirmed: 22/23 image requests served as `x-vercel-cache: HIT`, zero direct Supabase requests

### Phase 2: ISR + Query Optimization (~10-15% egress reduction)
- Switched `/talks` from `revalidate = 0` (SSR every request) to `revalidate = 3600` (ISR, 1 hour)
- Switched `/cards` from `revalidate = 0` to `revalidate = 86400` (ISR, 24 hours)
- Switched `/themes` from `revalidate = 0` to `revalidate = 86400` (ISR, 24 hours)
- Fixed N+1 query in `getAllTalks()`: replaced 101+ queries (1 + N per talk) with single LEFT JOIN + JS deduplication
- Fixed N+1 query in `getAllThemes()`: replaced 21 queries (1 + 2N per theme) with single query using correlated subqueries

### Phase 3: Query-Level Caching (~5% egress reduction)
- Wrapped `getAllCards()`, `getAllTalks()`, `getAllThemes()` in `unstable_cache` with cache tags
- Added `revalidateTag()` calls to all 10 admin mutation endpoints (cards, talks, themes, mappings) so cache busts immediately on admin changes
