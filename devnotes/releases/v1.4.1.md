# v1.4.1 - Focus & Context Flow + YouTube Title Parser

**Released:** February 3, 2026

## Summary

Enhanced the spread reading experience by making Focus and Context fully optional and visible throughout the entire reading journey. Also added intelligent YouTube title parsing for admin metadata extraction.

---

## Features

### Optional Focus & Context in Read My Spread

The "Read My Spread" modal now treats both focus category and personal context as truly optional.

- **"Read My Spread" button always visible** - No need to select a focus first
- **Focus chips toggle on/off** - Click to select, click again to deselect
- **Personal context textarea always visible** - Users can add context without selecting a focus
- **Defaults to "Surprise me"** - If no focus selected, reading proceeds without bias

### Focus & Context Displayed Throughout Journey

Focus and Context now flow through the entire reading experience:

| Location | Display |
|----------|---------|
| **"Your Reading" modal** | Below rationale with subtle divider |
| **"Get a Deeper Reading" (GPT)** | In clipboard text for pasting |
| **"Share Your Reading" modal** | In "With Text" format (rationale → focus/context → URL) |
| **Spread page (/spreads/[id])** | Below rationale in the public view |

### Gemini API Enhancement

Focus type label now included in Gemini synthesis prompt for better talk recommendations.

```
## USER FOCUS
Area: Relationships
Context: "love of my life"
```

Previously only `focusText` was sent; now `focusType` label (e.g., "Grief / Healing") is also passed.

### YouTube Title Parser (Admin)

New `parseYouTubeTitle()` function extracts speaker name and event name from YouTube video titles.

**Supported formats:**
- `"Pico Iyer: The art of stillness"` → Speaker: Pico Iyer
- `"Title | Speaker Name | TED"` → Speaker + Event
- `"Speaker -- Title | TEDxBoston"` → Speaker + Event

**Benefits:**
- Speaker name auto-populates when only YouTube URL provided
- Event name field added to metadata fetcher UI
- TED oEmbed speaker still takes priority when available
