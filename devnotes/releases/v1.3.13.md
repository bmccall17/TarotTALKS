# v1.3.13 - Theme Management & Talk Language Indicator

**Released:** February 2, 2026

## Summary

Added full theme management to the admin portal and a language indicator to the talks list. Admins can now create, edit, filter, and delete curated themes directly from the admin interface.

---

## Features

### Theme Management Admin Interface

Full CRUD interface for managing curated themes at `/admin/themes`.

**List View:**
- Table displaying name, slug, category badge, cards count, talks count
- Search themes by name or description
- Filter by category (emotion, life_phase, role, other)

**Create/Edit Form:**
- Name field with auto-generated slug
- Category dropdown selector
- Short description (required)
- Long description (optional)
- Slug is read-only after creation to prevent broken links

**Delete:**
- Confirmation dialog showing impact (cards/talks count)
- Hard delete with cascade to cardThemes/talkThemes

**Category Badges:**
- Emotion: Pink
- Life Phase: Blue
- Role: Purple
- Other: Gray

### Talk Language Indicator

Added language column to the admin talks list showing the talk's language as a subtle badge.

- Displays language code (e.g., `en`, `es`) in gray badge
- Shows dash (—) for talks without language set
- Appears between Year and Mappings columns

## Query Functions Added

```typescript
getAllThemesForAdmin(category?)     // List all with counts, optional category filter
getThemeByIdForAdmin(id)            // Single theme with counts
createTheme(data)                   // Insert with slug collision handling
updateTheme(id, data)               // Update theme
deleteTheme(id)                     // Hard delete with audit log
searchThemesForAdmin(query)         // Search by name/description
getThemesStats()                    // Total count and by-category breakdown
```
