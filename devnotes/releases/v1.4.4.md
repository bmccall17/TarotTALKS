# v1.4.4 - Admin API Monitoring Dashboard & Test Mode Fixes

**Released:** February 3, 2026

## Summary
Enhanced the admin API monitoring dashboard with circuit breaker visualization, quota tracking, usage graphs, and educational tooltips. Also fixed test mode (`?analytics_test=1`) to properly skip API calls and database saves.

---

## Features

### Circuit Breaker Visibility
- **Status badge**: Shows "CIRCUIT OPEN" with countdown timer when Gemini quota is exhausted
- **Help tooltip**: Info icon (?) next to Gemini explains the circuit breaker mechanism, metrics, and states
- **Force Reset button**: Admin can manually reset the circuit breaker with a warning about potential 429 errors

### Quota Tracking
- **Daily quota counter**: Shows "X / 1500" calls used today with visual progress bar
- **Color-coded progress**: Green (< 70%), Yellow (70-90%), Red (> 90%)
- **Smart counting**: Circuit breaker blocked calls are noted but not counted against quota

### Usage Graph
- **24-hour sparkline**: Bar chart showing hourly API usage
- **Success/failure breakdown**: Green bars for success, red for failures
- **Hover tooltips**: Shows exact counts per hour

### Log Tooltips
- **Detailed explanations**: Hover over any Gemini log row to see what the error means
- **Actionable guidance**: Each error type explains what to do (e.g., "Wait for midnight PT reset")
- **Technical details**: Shows HTTP status, retry attempts, circuit breaker status

### Test Mode Fixes
- **No database pollution**: Spreads are NOT saved when `?analytics_test=1` is active
- **No false API logs**: YouTube "spread_selection" logs only appear when YouTube was actually used
- **Debug visibility**: `_debug.saveSkipped` now shows in API response
