# v1.6.3 - Vercel Free-Tier Optimization: ISR & CDN Caching

**Released:** Feb 7, 2026

## Summary
Comprehensive caching pass to reduce Vercel paid usage (Function Execution, Source Image, Fast Origin Transfer) that spiked around Jan 29th. Added 24-hour ISR caching to all dynamic OG/Twitter image routes, switched detail pages from SSR to ISR, and enabled CDN caching on the search API. Partial ship — listing page caching deferred due to Vercel build timeout constraint.

---

## Features
- **OG/Twitter image caching (Phase 1):** All 5 uncached dynamic image routes now have `revalidate = 86400` (24h ISR). Social bot crawls and link previews no longer trigger serverless function + Satori PNG generation on every request.
- **Detail page ISR (Phase 2):** Card, talk, and theme detail pages switched from `revalidate = 0` (SSR every request) to ISR caching. Cards/themes cache for 24h, talks cache for 1h. `generateStaticParams()` returns empty array to skip build-time pre-rendering.
- **Search API CDN caching (Phase 3):** Search results now cached at CDN for 60 seconds with 5-minute stale-while-revalidate, reducing function execution for repeated queries.
- **Test script:** Added `scripts/test-vercel-optimization.sh` to verify all caching configurations across all 4 phases + guard rails for Instagram routes.
- **Audit workflow (`/audit`):** New agent workflow for repeatable codebase audits across 8 dimensions (API wiring, Gemini model usage, architecture, security, hygiene, cost, resilience, database) with 71 concrete checks. Produces versioned reports at `devnotes/audits/YYYY-MM-DD.md`. Supports single-dimension (`/audit security`), multi-dimension, and `--skip` invocation.
- **Workflow sync rule:** Added `## Workflow Sync` section to `CLAUDE.md` requiring all workflows to exist in both `.claude/commands/` (Claude Code) and `.agent/workflows/` (Antigravity). Created `.agent/RULES.md` as Antigravity's equivalent of `CLAUDE.md` with all project constraints (free tier, git restriction, domain, live testing, workflow sync).

## Known Workaround
- **Listing pages (`/cards`, `/talks`, `/themes`) remain SSR (`revalidate = 0`).** ISR causes Vercel build timeout (Supabase queries exceed 60s during build). Documented in `devnotes/vercel-optimizations-feb-2026.md` with future fix options.

## Addendum: IG Square Image Pipeline (Feb 7, 2026)

Added support for downloading and processing Instagram 1:1 square (1080x1080) images across 3 variants: Card+Talk, Card-Only, and Talk. Extends the existing campaign pipeline which only handled 4:5 portrait feed images.

### Features
- **One-off download script (`campaign:download-squares`):** Reads existing `all-cards-ig` manifest, queries DB for primary card→talk mappings, downloads 3 square images per card from live Satori routes, converts PNG→JPG via Sharp. Idempotent (skips existing files).
- **Campaign UGC pipeline update:** `campaign:ugc` now downloads square source PNGs and renders clean + UGC-treated variants for all 3 square types alongside the existing 4:5 feed images.
- **Square render spec:** Added `square_1x1` to `PLATFORM_RENDER_SPECS` for Instagram. Added `SquareVariant` type and `SQUARE_VARIANTS` constant for programmatic access.
- **`talk_slug` on CampaignItem:** New optional field populated from primary card→talk mappings, used to resolve talk square image URLs.

### New Files
- `scripts/campaign-download-ig-squares.ts` — One-off script to backfill square images for all 78 cards

### Modified Files
- `lib/campaign/types.ts` — Added `square_1x1` render spec, `SquareVariant` type, `SQUARE_VARIANTS` constant, `talk_slug` field
- `scripts/campaign-ugc.ts` — Square source download in `download()`, square clean+UGC rendering in `render()`, primary talk query in `ingestAllCards()`
- `package.json` — Added `campaign:download-squares` npm script
