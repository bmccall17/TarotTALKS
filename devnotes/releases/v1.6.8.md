# v1.6.8 - Operational Runbooks 📋🔧

**Released:** Mar 5, 2026

## Summary
Created a suite of 6 operational runbooks covering the most critical maintenance domains across the project. These are quick-reference guides for diagnosing issues and maintaining TarotTALKS when coming back after time away — distilled from real incidents and release history spanning v1.0 through v1.6.7.

---

## Features
- **Runbooks directory** (`devnotes/runbooks/`) — Centralized location for all operational documentation
- **Admin Performance runbook** — Diagnostic tools, the 3 traps (Drizzle dates, Vercel timeouts, stale builds), DB health checks
- **Database Safety runbook** — Safe seeding workflow, export checklist, migration steps, recovery options (based on Dec 2025 data loss incident)
- **Cost Control runbook** — Weekly audit checklist, service cost map, spike diagnosis guide, emergency cost-cut levers, caching architecture reference
- **Security Checklist runbook** — Current vulnerability status (Snyk baseline), secret rotation procedures per service, hardening sprint checklist
- **Social Share Images runbook** — Satori/Supabase diagnosis flowchart, bucket permission checks, WebP migration incident notes, rollback steps
- **Deployment & Vercel runbook** — Hobby plan limits, `maxDuration` requirement for new routes, stale build detection, ISR/caching quick reference, Drizzle ORM gotchas
