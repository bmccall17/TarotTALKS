# v1.5.1 - Gemini 2.0 Flash Migration

**Released:** Feb 3, 2026

## Summary
Fixed Gemini API 404 errors by migrating from the deprecated `gemini-1.5-pro` model to `gemini-2.0-flash`. Added diagnostic tooling to debug API issues.

---

## Features
- Migrated from `gemini-1.5-pro` (deprecated by Google) to `gemini-2.0-flash`
- Added `/api/admin/test-gemini` debug endpoint for API diagnostics
- Added `?action=list-models` query to discover available Gemini models
- Added diagnostic logging to show exact API URLs in Vercel function logs

---

## Root Cause
Google deprecated `gemini-1.5-pro` - the model no longer exists in the Generative Language API. The fix in v1.5.0 updated the endpoint format but the model itself was removed by Google.

---

## Files Changed

### New Files
- `app/api/admin/test-gemini/route.ts` - Debug endpoint for testing Gemini API connectivity

### Modified Files
- `lib/services/gemini.ts` - Updated `GEMINI_MODEL` and `GEMINI_MODEL_ENDPOINT` from `gemini-1.5-pro` to `gemini-2.0-flash`, added diagnostic logging
