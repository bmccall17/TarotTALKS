# v1.7.2 - Sentry Observability Wiring 🔭

**Released:** Apr 13, 2026

## Summary
Wires up Sentry for real observability: correct project name, area tagging on every request, and explicit span instrumentation on the admin Spreads and Share Images data fetches so slow queries show up in Trace Explorer with duration data.

---

## Features
- Renamed Sentry project slug from `javascript-nextjs` → `tarottalks` so source maps and events route to the correct project
- Added `Sentry.setTag('area', 'admin' | 'public')` in middleware — every request is now tagged for per-area filtering and alerting in Sentry
- Extended middleware matcher from `['/admin/:path*', '/api/admin/:path*']` to `['/admin/:path*', '/api/:path*']` so public API routes also receive the `area: public` tag
- Added `Sentry.startSpan` instrumentation to admin Spreads fetches (`fetchStats`, `fetchSpreads`) — spans appear in Trace Explorer as `admin.spreads.fetchStats` and `admin.spreads.fetchSpreads`
- Added `Sentry.startSpan` instrumentation to admin Share Images fetches (`fetchCards`, `fetchTalks`, `fetchStoredImages`) — spans appear as `admin.shareImages.*`
- Span attributes included where useful: `filter` and `offset` on spreads fetches, `category` on stored images fetch

---
