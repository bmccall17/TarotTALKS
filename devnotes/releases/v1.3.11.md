# v1.3.11 - GPT Fallback & Independent API Handling

**Released:** February 2, 2026

## Summary

When Gemini API is unavailable (rate limited or down), users now see a GPT fallback option with a modal that helps them copy their spread and continue to the TarotTALKS GPT. Also separated Gemini and YouTube API failure handling so each can fail independently.

---

## What Changed

### GPT Fallback UI (`ResultDisplay.tsx`)

**When Gemini is unavailable** (using template rationale), the action buttons now split:
- **Refresh icon** (gray) — "Try Another" with tooltip
- **OpenAI icon** (emerald green) — Opens GPT modal with tooltip "✨ Want a deeper reading? Try the TarotTALKS GPT →"

**When Gemini is available** (AI rationale), standard "Try Another" button appears as before.

### New GPT Fallback Modal (`GPTFallbackModal.tsx`)

New component that appears when clicking the OpenAI button:
- Displays spread text: `Aware Self: [Card], Supporting Shadow: [Card], Emerging Path: [Card]`
- Copy to clipboard option (auto-enabled on mobile, checkbox on desktop)
- "Cancel" and "Copy & Continue to GPT" buttons
- Opens TarotTALKS GPT in new tab

### Independent API Fallbacks (`route.ts`)

Gemini and YouTube APIs now fail independently:

| Gemini | YouTube | Behavior |
|--------|---------|----------|
| ✅ | ✅ | Full AI: synthesis → YouTube + local → AI selection |
| ✅ | ❌ | Partial AI: synthesis → local only → AI selection |
| ❌ | ✅ | Fallback: local scoring + template rationale |
| ❌ | ❌ | Full fallback: local scoring + template rationale |

New response fields:
- `youtubeUsed: boolean` — Whether YouTube candidates were included
- `_debug.geminiAvailable` — Gemini API status
- `_debug.youtubeAvailable` — YouTube API status

### YouTube API Key Fix (`youtube.ts`)

Fixed potential issue where API key was captured at module load time. Now reads at runtime via `getYouTubeApiKey()` function.

### Gemini Model Update (`gemini.ts`)

Updated from deprecated `gemini-1.5-flash` to `gemini-2.0-flash`.

### Admin Developer Tools (`behavior/page.tsx`)

Added "Developer Tools" section at bottom of Behavior analytics page:
- Test Mode ON: `?analytics_test=1` (skips Gemini/YouTube APIs)
- Test Mode OFF: `?analytics_test=0`
