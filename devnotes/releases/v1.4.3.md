# v1.4.3 - Deployment Pipeline Fix

**Released:** Feb 3, 2026

## Summary
Fixed critical Vercel deployment failures caused by oversized uploads and a TypeScript error in the circuit breaker implementation.

---

## Features
- Added `.vercelignore` to exclude large/unnecessary files from Vercel CLI deployments
- Fixed TypeScript error: added `circuit_breaker` to `ErrorType` union
- Updated `.gitignore` to prevent `.agent/` directory from being tracked

---

## Files Changed

### New Files
- `.vercelignore` - Excludes docs/, devnotes/, screenshots, node_modules from Vercel uploads

### Modified Files
- `.gitignore` - Added `.agent/` to ignored paths
- `lib/db/queries/api-usage.ts` - Added `circuit_breaker` to ErrorType union

---

## Technical Details
- **Root cause:** Vercel CLI was uploading 3.1GB (docs folder) instead of ~1KB of actual code
- **Secondary issue:** TypeScript build failed due to missing `circuit_breaker` type in ErrorType
- **Resolution:** `.vercelignore` reduces upload size; type fix allows builds to complete
