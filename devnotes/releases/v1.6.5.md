# v1.6.5 - Platform Quotas Monitor: Admin Dashboard & Behavior Traffic Chart

**Released:** Feb 8, 2026

## Summary
Adds a "Platform Quotas" panel to the Admin Dashboard and a daily sessions traffic chart to the Behavior page, giving at-a-glance visibility into Supabase and Vercel free-tier limits without leaving the app. Follows the v1.6.4 egress reduction work — now you can monitor whether the fixes are holding.

---

## Features

### Platform Quotas Panel (Admin Dashboard)
- **Billing cycle bar** — shows "Day X of Y — Z days remaining" with progress bar, aligned to the 16th–16th Supabase/Vercel billing cycle
- **DB Size card** — queries Postgres for actual database size against the 500 MB Supabase limit, with color-coded progress bar (green/yellow/orange/red at 50%/75%/90% thresholds)
- **Image Sources card** — counts distinct card image URLs + talk thumbnail URLs against Vercel's 1,000 source image limit
- **Daily Sessions card** — today's session count vs 7-day daily average with trend arrow (up/down/stable) and egress warning
- **Dashboard links** — direct links to Supabase Usage and Vercel Usage dashboards
- **Resilient queries** — each metric has independent error handling; one failed query won't break the whole panel (falls back to safe defaults)
- **DB size fallback** — if `pg_database_size()` is blocked by Supabase pooler, falls back to summing public table sizes

### Daily Sessions Chart (Behavior Page)
- **Bar chart** at the top of the Behavior page showing sessions per day for the selected time range (7/14/30 days)
- **Today's bar highlighted** in brighter indigo for quick identification
- **Average line** drawn across for reference with label
- **Hover tooltips** showing exact date and session count per bar
- **Responsive X-axis labels** — shows first, middle, and last date
- Data comes from the existing `/api/admin/behavior` endpoint (extended with `dailySessions` array)

## Files Changed

### New Files
- `lib/db/queries/admin-platform-usage.ts` — Query functions: `getBillingCycleInfo()`, `getDatabaseSize()`, `getImageSourceCount()`, `getSessionTrend()`, `getAllPlatformUsage()`

- `components/admin/dashboard/PlatformQuotasSection.tsx` — Client component with billing cycle bar, three quota cards, and dashboard links

### Modified Files
- `app/admin/page.tsx` — Added `<PlatformQuotasSection />` below `<ApiHealthSection />`
- `app/admin/behavior/page.tsx` — Added `DailySessionsChart` component and `dailySessions` type; chart renders at top of page

- `lib/db/queries/admin-behavior.ts` — Added `getDailySessionCounts()` query, extended `BehaviorStats` type and `getAllBehaviorStats()` to include `dailySessions`
