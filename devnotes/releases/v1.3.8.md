# v1.3.8 - Smart Bluesky Post URL Handling

**Released:** January 31, 2026

## Summary

Enhanced Bluesky integration with intelligent URL extraction from rich text facets and auto-population of form fields when pasting Bluesky post URLs. The mentions scanner and rescan features now properly detect TarotTALKS links embedded in Bluesky's rich text format.

---

## Features

### Smart URL Extraction from Bluesky Facets

**Problem:** Bluesky stores hyperlinks in "facets" (rich text metadata), not in plain text. When users post links, the URL is in the facets array, which means our regex-based URL extraction from post text often missed TarotTALKS links.

**Solution:** Added facets-aware URL extraction that checks facets first, then falls back to text parsing.

**New Helper Functions in `lib/services/bluesky.ts`:**
- `extractTarotTalksUrlFromFacets()` - Extracts URLs from Bluesky facets (rich text links)
- `extractTarotTalksUrlFromText()` - Fallback extraction from plain text
- `extractTarotTalksUrl()` - Combined function that tries facets first, then text

**Updated Types:**
- Added `BlueskyFacet` type for Bluesky's rich text metadata
- Added `facets` field to `FullPostData` and `MentionPost` types

### Auto-Fetch for NewShareForm

When pasting a Bluesky post URL in the "Log New Share" form:
- Shows "Fetching..." spinner while loading
- Auto-populates:
  - **TarotTALKS URL** - Extracted from facets or text
  - **Card/Talk** - Resolved from the URL
  - **Posted At** - Actual post timestamp
  - **Notes** - Full post text
  - **Status** - Set to "verified"
  - **Metrics** - Like, repost, and reply counts
- Shows "Auto-filled" indicator on success
- Shows error message if fetch fails (with note that manual entry still works)

### New API Endpoint

**`POST /api/admin/social-shares/fetch-post`**

Fetches and processes a Bluesky post URL, returning:
- Post text and timestamp
- Author handle and display name
- Extracted TarotTALKS URL (from facets or text)
- Resolved card/talk IDs and content name
- Engagement metrics

## Bug Fixes

### Mentions Scanner Now Detects Rich Text Links

**Problem:** The Bluesky mentions scanner was using regex on post text only, missing links embedded as rich text facets.

**Solution:** Updated `app/api/admin/mentions/route.ts` to use `extractTarotTalksUrl(mention.text, mention.facets)` which checks facets first.

### Rescan Now Handles Facets

**Problem:** The rescan feature was also using text-only regex, missing facet-embedded URLs.

**Solution:** Updated `app/api/admin/social-shares/[id]/rescan/route.ts` to use the facets-aware extraction.
