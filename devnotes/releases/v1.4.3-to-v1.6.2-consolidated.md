## v1.5.2 - Bibliography RAG Cleanup & Thumbnail Upscaling

**Released:** Feb 4, 2026

Paused the Bibliography Storage feature (RAG 1.0) after research revealed fundamental limitations. Added automatic thumbnail upscaling for social sharing quality.

### Bibliography RAG Cleanup
- Removed RAG 1.0 ingestion pipeline (naive chunking approach deemed insufficient)
- Cleaned up ~14MB of broken/oversized generated SQL
- Preserved PDF collection for future RAG 2.0 (Docling + Jina Embeddings + Hybrid Search)

### Thumbnail Upscaling
- All new talk thumbnails automatically upscaled to 1280x720 WebP
- Uses Sharp with Lanczos3 interpolation
- 25-30% smaller than JPEG via WebP compression
- Graceful fallback to original on failure

## v1.6.0 - Static Social Share Images via Supabase Storage

**Released:** Feb 6, 2026

Pre-generate all social share images as static PNGs in Supabase Storage so social platform crawlers fetch from CDN instead of triggering Vercel serverless Satori generators. Eliminates serverless function invocations for every share link crawl.

### Static Image Pipeline
- `share-images` Supabase Storage bucket with deterministic paths (`{category}/{type}/{slug}.png`)
- Generation API: `POST /api/admin/share-images/generate` - fetches from Satori, uploads to Supabase, updates DB
- List API: `GET /api/admin/share-images/list` - queries bucket for existing images
- Thumbnail upscale API: `POST /api/admin/talks/[id]/upscale-thumbnail`

### Metadata Fallback Chain
- Pages prefer: `shareImageUrl` (static Supabase) > `thumbnailUrl` (raw) > dynamic Satori generator

### Admin Enhancements
- Share Images page rewrite: per-item Generate buttons, "Generate All Missing" batch with progress
- TalkRow/CardRow: New ImagePlus button for one-click image generation
- Edit pages: Live site URLs with click-to-copy, clickable previews linking to live pages

### Database Migration
- `share_image_url` column added to `talks`, `cards`, and `spreads` tables

**Files:** 5 new, 13 modified

## v1.6.2 - Social Campaign Asset Pipeline & Signal Deck Parity

**Released:** Feb 6, 2026

Multi-platform social campaign CLI pipeline with Instagram image parity, UGC styling, AI caption generation, Signal Deck UI enhancements, and a one-command pipeline to generate Instagram assets for all 78 cards.

### Phase 1: Instagram Feed Image Generators
- Instagram Feed portrait (1080x1350) image routes for cards and talks
- Extracted shared Satori helpers (fonts, sparkles) into `satori-helpers.ts`
- Added `instagram-feed` and `linkedin` types to storage pipeline

### Phase 2: Campaign CLI Pipeline
- `campaign:ingest` - Build manifest from Signal Deck DB, CSV, or JSON input
- `campaign:download` - Fetch source images with 3x retry + exponential backoff
- `campaign:render` - Sharp resize to platform specs (Instagram 4:5, X/Bluesky/LinkedIn OG)
- `campaign:index` - Generate per-platform `_index.csv` and `_summary.json`
- All scripts idempotent, output to `/campaigns/` (gitignored)

### Phase 3: UGC Image Styling
- Sharp-based treatments: crop offset, grain noise overlay, warm color shift, SVG watermark, JPEG quality 88
- `ugc_` prefixed variants alongside clean renders via `--ugc` flag

### Phase 4: Gemini Caption Generation
- Platform-aware AI captions (short/medium/spicy variants + `#` prefixed hashtags)
- ~$0.0001 per item via Gemini 2.0 Flash

### Phase 5: Signal Deck UI Enhancements
- **PostPreview** - Platform-specific post mockups with live card/talk images
- **HashtagSuggester** - Card-aware hashtag pools, all selected by default, click-to-deselect
- **ExportToCampaign** - Bulk export to campaign JSON, auto-closes after download
- Select/Export buttons inline with date filters via `leftActions` slot

### Phase 6: All-in-One UGC Script
- `campaign:ugc` - Single command: ingest -> download -> render (UGC + captions) -> index
- `--source all-cards` mode: queries all 78 cards from DB, bypasses Signal Deck
- Live Satori route URLs for downloads (no pre-generation needed)
- Smart manifest merge: refreshes existing items instead of skipping stale entries

### Key Command
```bash
npm run campaign:ugc -- --campaign all-cards-ig --source all-cards --platform instagram
```

### Bug Fixes
- UGC variant generation skipped when clean render already existed (idempotency bug)
- Caption generation skipped when clean render already existed (same class)
- Download HTTP 400: switched from Supabase storage URLs to live Satori route URLs
- Stale manifest: merge logic now refreshes existing items
- Square 1:1 images parked for future sprint (crops talk info)

**Files:** 16 new, 8 modified
