# v1.5.0 - Gemini Pro Upgrade & Budget Tracking 💰

**Released:** Feb 3, 2026

## Summary

Upgraded from Gemini 2.0 Flash (free tier) to Gemini 1.5 Pro (paid tier) with comprehensive cost tracking and budget monitoring. The admin dashboard now displays real-time spending, monthly budget status, and color-coded alerts to ensure the $88/month budget is never exceeded.

## Features

### Gemini 1.5 Pro Model
- Upgraded from `gemini-2.0-flash` to `gemini-1.5-pro-latest`
- Higher quality reasoning for spread readings
- Increased rate limits (30 RPM vs 10 RPM)

### Cost Tracking Infrastructure
- Every API call now logs input/output token counts
- Automatic cost calculation based on Gemini pricing ($1.25/1M input, $5.00/1M output)
- Console logs show per-call costs: `[Gemini] gemini-1.5-pro: 723 in + 156 out = $0.001683`

### Budget Monitoring Dashboard
- **Progress bar** with color-coded status (green/yellow/orange/red)
- **Stats grid**: Remaining budget, daily average, projected monthly spend
- **Today's spend widget**: Real-time tracking with token counts
- **Alert levels**:
  - OK (green): < 50% used
  - Warning (yellow): 50-75% used
  - Danger (orange): 75-90% used
  - Critical (red): > 90% used

### Database Schema Updates
- New columns on `api_usage_events`:
  - `input_tokens` (INTEGER)
  - `output_tokens` (INTEGER)
  - `cost_usd` (REAL)
  - `model_id` (VARCHAR)

## Migration Required

Run in Supabase SQL Editor:

```sql
ALTER TABLE api_usage_events ADD COLUMN IF NOT EXISTS input_tokens INTEGER;
ALTER TABLE api_usage_events ADD COLUMN IF NOT EXISTS output_tokens INTEGER;
ALTER TABLE api_usage_events ADD COLUMN IF NOT EXISTS cost_usd REAL;
ALTER TABLE api_usage_events ADD COLUMN IF NOT EXISTS model_id VARCHAR(50);

CREATE INDEX IF NOT EXISTS idx_api_usage_cost ON api_usage_events(cost_usd) WHERE cost_usd IS NOT NULL;
```
