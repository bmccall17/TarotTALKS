# v1.4.2 - Signal Deck Evolve: Next Cards to Post Improve

**Released:** Feb 3, 2026

## Summary

Enhanced the Signal Deck's "Next Cards to Post" widget with direct admin links, TagPack pre-population, and speaker info auto-fill to streamline the social sharing workflow.

---

## Features

### Card Name Links to Admin Edit
- Card names in "Next Cards to Post" now link directly to `/admin/cards/{id}/edit`
- Quick access to edit card details without searching

### TagPack Pre-Population
- Clicking "Share" fetches the card's TagPack data from new API endpoint
- Notes field auto-populates with formatted TagPack text:
  ```
  🎴 The Tower
  💬 "Rationale text here..."
  🎥 Talk Title
  🎤 Speaker Name
  ```
- Loading spinner shows during data fetch

### Speaker Info Auto-Fill
- Speaker Name and Speaker Handle fields pre-populate from talk metadata
- Reduces manual data entry for social shares
