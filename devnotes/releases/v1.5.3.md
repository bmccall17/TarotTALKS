# v1.5.3 - Instagram Share Images for Cards & Talks 📸

**Released:** Feb 4, 2026

## Summary
Comprehensive Instagram share image system with optimized 1080x1080 layouts for both cards and talks, plus enhanced admin tooling for managing all share image variants.

---

## Features
- **Card Instagram (Card+Talk)** - New default layout showing card overlaying talk thumbnail, large card name (90px), speaker name under card
- **Card Instagram (Card-only)** - Legacy variant preserved via `?v=card` query param
- **Talk Instagram** - New route showing prominent talk thumbnail, title/speaker left-justified, card image with name aligned to bottom-right
- **Admin Share Images Page** - Updated to show both card variants and talk Instagram previews
- **Footer Removal** - Removed "tarottalks.app" footer from all OG image generators (cards, talks, spreads)

---

## Files Changed

### New Files
- `app/talks/[slug]/instagram/route.tsx` - Talk Instagram image generator (1080x1080)

### Modified Files
- `app/cards/[slug]/instagram/route.tsx` - Added Card+Talk layout, query param support for card-only variant
- `app/admin/share-images/page.tsx` - Shows both card IG variants, talk IG preview, updated save/download logic
- `app/api/admin/share-images/save/route.ts` - Support for `instagramCardOnly` type
- `app/spreads/[id]/opengraph-image.tsx` - Removed footer URL
- `app/spreads/[id]/twitter-image.tsx` - Removed footer URL
