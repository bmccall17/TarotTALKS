# v1.4.5 - Admin Spreads Query Fix

**Released:** February 3, 2026

## Summary
Fixed the Admin:Spreads Management view showing empty data due to a raw SQL array query bug.

---

## Bug Fix

### Admin Spreads Management Empty View
- **Problem**: The spreads list was showing empty despite database having records
- **Cause**: Raw SQL using `ANY(${cardIds})` doesn't properly serialize JavaScript arrays to PostgreSQL array format
- **Solution**: Replaced with Drizzle's `inArray()` function which correctly parameterizes arrays
- **Bonus**: Added empty array guard to prevent edge case errors when spreads have no linked cards

---

## Files Changed

### Modified Files
- `lib/db/queries/admin-spreads.ts` - Fixed `getSpreadsForAdmin()` query:
  - Added `inArray` to drizzle-orm imports
  - Replaced `sql\`${cards.id} = ANY(${cardIds})\`` with `inArray(cards.id, cardIds)`
  - Added conditional to handle empty `cardIds` arrays gracefully

---

## Code Audit

A full audit of raw SQL usage across the codebase confirmed:
- No SQL injection vulnerabilities
- All other array operations use proper `sql.join()` or `inArray()` patterns
- This was the only instance of the problematic `ANY()` pattern
