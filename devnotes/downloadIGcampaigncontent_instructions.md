# v1.6.2 Phase 6 - Campaign UGC Pipeline Instructions

## Generate Instagram Assets for All 78 Cards

This is the main command. It queries every card from the database, downloads the 1080x1350 feed image from the live Satori route, renders clean + UGC variants, generates AI captions via Gemini, and builds an index.

```bash
npm run campaign:ugc -- --campaign all-cards-ig --source all-cards --platform instagram
```

**What it does (4 steps):**

1. **Ingest** - Queries all 78 cards from the DB, builds a manifest with live image URLs
2. **Download** - Fetches each card's instagram-feed image (1080x1350) from `https://tarottalks.app/cards/{slug}/instagram-feed`
3. **Render** - Resizes to `feed_4x5.jpg` (1080x1350, quality 95) + UGC variant (`ugc_feed_4x5.jpg` with grain, warmth, watermark) + AI captions via Gemini (short/medium/spicy + hashtags)
4. **Index** - Generates `instagram/_index.csv` and `_summary.json`

**Expected runtime:** ~3-5 minutes (78 image downloads + 78 Gemini API calls with 2s rate limit between each).

**Expected Gemini cost:** ~$0.008 total (78 items x ~$0.0001 each via Gemini 2.0 Flash).

## Verify After Running

1. Check the summary:
   ```bash
   cat campaigns/all-cards-ig/_summary.json
   ```
   Should show `"total": 78, "ready": 78`.

2. Spot-check a few cards:
   ```bash
   ls campaigns/all-cards-ig/instagram/2026-02-06_the-tower/
   ```
   Should contain: `source.png`, `feed_4x5.jpg`, `ugc_feed_4x5.jpg`, `caption_short.txt`, `caption_medium.txt`, `caption_spicy.txt`, `hashtags.txt`, `metadata.json`.

3. Open a UGC image and compare with the clean version - UGC should have subtle grain, warmer colors, and a faint "tarottalks.app" watermark bottom-right.

4. Open `hashtags.txt` - should have `#` prefixed tags like `#tarot #thetower #awakening`.

## Idempotency

Re-running the same command is safe. It will:
- Skip already-downloaded source images
- Skip already-rendered clean and UGC variants
- Skip already-generated captions
- Only process missing items

```bash
# Safe to re-run - skips everything already done
npm run campaign:ugc -- --campaign all-cards-ig --source all-cards --platform instagram
```
